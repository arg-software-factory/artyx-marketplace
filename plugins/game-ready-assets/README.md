# Game-Ready Assets

Five skills that carry the rules a game artist applies before an asset ships.
Skills only: no server, no account, no setup.

| Skill | Use it for |
|---|---|
| `poly-budgets-lods` | Triangle, material, bone, and draw-call budgets per platform; LOD chains per engine |
| `topology-and-uvs` | Clean topology, normals and smoothing, UV layout, padding, lightmap UVs |
| `texel-density` | Pixels per meter targets, texture size from surface area, verification |
| `pbr-texture-sets` | Map naming, ORM and mask-map packing, normal-map conventions, compression |
| `engine-export` | Units, axes, pivots, collision and LOD naming, FBX and glTF settings for Unity, Unreal, Godot, and Blender |

The numbers in the skills are common industry starting points. A project's own
measured budget and standards always win; the skills tell the agent to ask for
them first.
